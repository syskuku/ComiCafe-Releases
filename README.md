# ComiCafe

**AI 浪潮下的 ACGN 新型创作平台**

ComiCafe 以创作为核心，以社团为创作与收益主体，以质量为推流导向，在平台内形成创作与交易的闭环。

- 考核制准入，通过考核即可创建社团。
- 作品、成品、素材在平台内完成从创作到交易的闭环。
- 两种代币，一种兑换券：幻想币、赛钱、盲灵符。

官网：<https://comi.cafe>

ComiCafe Android 官方应用正在开发中。关注项目进展，成为第一批通过考核的创作者。期待大家预约内测。

## Android 内测分发

本仓库仅用于 ComiCafe Android 内测版 APK 分发与更新记录，不存放源代码。当前版本仅面向已获得内测资格的 ComiCafe 用户。
